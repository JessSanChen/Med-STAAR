## Provider Contract

Column names:
   1. Contract type → Whether the provider is Full-Time (FT) or Independent Contractor (IC).
Shift preference → Indicates which shifts (MD1, MD2, PM) the provider prefers or is eligible for.
Total shift count → Total number of shifts provider should be scheduled in a month
Weekend shift count → Number of weekend shifts provider should be scheduled for.
PM shift count → Number of night/PM shifts provider should be scheduled for.
